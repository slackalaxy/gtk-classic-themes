# ThinIce (GTK2 + GTK3 + GTK4)

GTK3 and GTK4 port of the gtk-engines 2.20.2 ThinIce theme (engines/thinice/src/thinice_theme_draw.c, themes/ThinIce/gtk-2.0/gtkrc). The original GTK2
gtkrc is included.

Install: copy the `ThinIce` folder to `~/.themes/` and select it as the GTK theme. Restart running applications after replacing the theme.
Applications built on libadwaita ignore third-party GTK4 themes.
