# Clearlooks (GTK3 + GTK4)

GTK3 and GTK4 recreation of the GTK2 Clearlooks theme (Gummy style) from gtk-engines 2.20.2.
Install: copy the `Clearlooks` folder to `~/.themes/`.

See `gtk-3.0/gtk.css` and `gtk-4.0/gtk.css` for the design notes. Not done yet: Quicksilver variant,
GTK2-style focus box on tab labels. GTK4 scrollbars have no stepper buttons. Applications built on libadwaita
ignore third-party GTK4 themes.
